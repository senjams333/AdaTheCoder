How to install Ada The Coder

About 5 minutes, and you only do it once. New lessons then arrive by themselves.

💻 Windows 10 or 11 · about 500 MB free

  1. 1

    Download the installer

    Click ⬇ Windows on the Free Trial card. The file AdaTheCoder Setup saves to your Downloads folder.

  2. 2

    Open the file

    Double-click AdaTheCoder Setup to start.

    If a blue box says “Windows protected your PC”, click More info → Run anyway. If asked to allow changes, click Yes.

  3. 3

    Follow the installer

    Click Next, tick Create a desktop shortcut, then Install and Finish.

  4. 4

    Start coding!

    Open Ada The Coder from the desktop or Start menu and begin the first lesson.

🍎 macOS 11 (Big Sur) or newer · about 500 MB free

  1. 1

    Download the app

    Click ⬇ Mac on the Free Trial card. A .dmg file saves to your Downloads folder.

  2. 2

    Drag to Applications

    Double-click the file, then drag the Ada The Coder icon onto the Applications folder.

  3. 3

    Open it the first time

    In Applications, right-click Ada The Coder → Open → Open.

    Still blocked? Go to System Settings → Privacy & Security and click Open Anyway.

  4. 4

    Keep it handy

    Right-click the icon in the Dock → Options → Keep in Dock, so your child can find it again.
